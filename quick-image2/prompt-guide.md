## 1. 六段式骨架

直接填空，每段一句，段与段用逗号连接：

```
[主体 + 外观特征]，[场景/背景]，[视角与构图]，[风格]，
[光线与时间]，[主色-辅色]，[画面文字（可选）]，[画质要求]
```

- 主体：只写看得见的东西，不写心情与用途
- 视角：平视 / 俯视 / 仰视 / 特写 / 全身 / 远景；构图：居中 / 三分 / 大量留白
- 风格只能选一种，混搭会互相抵消
- 光线写方向 + 时间，比"氛围感"有效十倍

## 2. 分场景模板

### 头像
`人物/动物半身特写，浅灰纯色背景，居中构图，干净自然的柔光，[主色] 为主调，无文字，面部清晰`

### 手机壁纸
`[主体] 竖版远景，上下大量留白，深色低饱和天空，[主色] 渐变，无文字，细节通透`

### 社交媒体封面（9:16）
`[主体] 位于画面中下部，上方 1/3 留白给标题，明亮通透的商业摄影风格，[主色]，画面文字"…"置于顶部居中，字形清晰`

### 电商主图（1:1）
`[商品] 正面角度，纯白背景，柔和顶光加轻微投影，主体居中占画面 60%，无任何文字与水印`

### 文章配图（4:3）
`[场景] 的自然纪实摄影，平视中景，[时间段] 柔和光线，低饱和真实色调，无文字`

### 海报草图（3:4）
`[主体] 居中或偏左，大面积色块背景，[风格] 的强对比配色，标题文字"…"位于下方 1/4，层级清晰`

### 人像写真（3:4）
`[人物] 半身，[服装] 的简约造型，浅景深虚化背景，平视略低于眼睛的高度，柔和侧逆光，肤色通透，面部细节清晰，无文字`

### 插画绘本（4:3）
`[主体] 与 [场景] 的扁平插画，边缘线条干净，色块平涂加轻微噪点质感，[主色] 双色系，构图疏朗，无文字`

### 图标 / Logo 草图（1:1）
`以 [核心意象] 为原型的极简图标，单色 [颜色] 实心，几何化处理，居中，白色背景，线条粗细一致，无文字无渐变`

### 信息图 / 概念示意（4:3）
`围绕 [主题] 的等距视角示意插画，[数量] 个元素各占独立位置，浅色背景，[主色] 用于强调，结构清晰、无拥挤，仅含标注文字"…"`

### 节庆海报（3:4）
`[主体] 居中偏上，[节庆] 的喜庆配色（红金为主），背景为低对比的纹样或光斑，标题文字"…"位于上部，副标题"…"位于下部，字形端庄可读`

## 3. 比例速查

| 比例 | 典型用途 |
|---|---|
| 1:1 | 头像、电商主图、商品卡片、社交方图 |
| 4:5 / 3:4 | 小红书、Instagram、竖版海报、单品图 |
| 9:16 | 手机壁纸、短视频封面、Story、开屏 |
| 16:9 | PPT 配图、网页横图、视频画面 |
| 2.35:1 / 1.91:1 | 公众号头图、横版主视觉 |
| 3:1 / 4:1 | 官网 Banner、店铺横幅 |

## 4. 常见翻车点与修法

| 现象 | 原因 | 修法 |
|---|---|---|
| 画面文字乱码、多出字母 | 文案没加引号，或文案过长 | 文案用中文引号包裹，压到 12 字以内 |
| 主体被裁 | 没写构图与留白 | 补"主体居中，四周保留 XX 留白" |
| 风格不统一 | 同时写了"写实 + 卡通 + 水彩" | 只留一种风格词 |
| 改图改崩 | 只写"换个背景" | 明确"仅替换背景为 XX，主体、姿态、光影不变，保持原图比例" |
| 出现多余元素 | 主体描述含糊 | 加"画面只有一个 [主体]，无其他人物与装饰" |

## 5. 负面词表

收尾统一带这五项，只按当次风险增补：

```
清晰，细节完整，无水印，无 logo，除指定文案外画面无其他文字
```

按场景选加（一次不超过 3 项，堆多了反而互相削弱）：

| 场景 | 该加的负面项 |
|---|---|
| 人物 | 畸形手指，多余肢体，脸部不对称 |
| 商品 | 文字标签，包装褶皱，反光污点 |
| 纯色背景 | 杂物，渐变条纹，纹理噪点 |
| 建筑/室内 | 透视歪斜，重复窗格，错位线条 |
| 系列图 | 各张之间风格、光线、配色不一致 |

## 6. 画面文字的排版

- 文案逐字照抄，用中文引号包住；不加标点、不翻译、不加英文副标
- 标题压到 12 字以内，副标题 20 字以内；字数越多越容易糊
- 位置说死：顶部居中 / 下方 1/4 / 左侧竖排；只说"加点文字"必然乱放
- 一个画面最多两级字号，层级靠字号和粗细拉开，不要靠颜色
- 字体只作风格暗示（如"黑体加粗""手写体"），不指定具体字库名
