# Quick Image

单张图片的快出流程。目标是：**问最少的、必要的几个问题，一次出对**。

## 先判断是哪一类

| 类型 | 用户典型说法 | 做法 |
|---|---|---|
| 新建 | "画一张""做个封面""生成一张壁纸" | 从零按提示词公式出图 |
| 改图 | "把这张换成夜景""去掉背景""换成插画风" | 必须基于原图，保持原图比例，只改用户点名的部分 |
| 参考迁移 | "照这个风格做一张" | 参考图只取风格/配色/构图，不复制主体与文字 |

## 只补三件事

信息不全时按默认值补齐，**不要为了确认而拦住用户**。只有当缺项会明显改变产出时才问，且一次问完。

| 缺什么 | 默认值 |
|---|---|
| 用途与比例 | 用途不明 → 1:1 方图；说"壁纸/手机" → 9:16；说"封面/短视频" → 9:16；说"PPT/头图" → 16:9；说"文章配图" → 4:3 |
| 主体 | 从用户原话里取最具体的那个名词，不要自己发挥加人加物 |
| 风格 | 用户没说 → 干净现代的商业摄影或扁平插画，配色不超过 3 个主色 |

用户明确要求的字必须原样保留，用中文引号"…"包住；没要求写字就不要让画面出现文字。

## 提示词公式

按这个顺序写，一句一项，不堆形容词：

1. **主体**：谁/什么，外观关键特征，数量
2. **场景与构图**：在哪里，视角（平视/俯视/特写），主体位置与留白
3. **风格**：摄影 / 3D 渲染 / 扁平插画 / 水彩 / 线稿 / 赛博 / 国潮 等，选一种说清
4. **光与色**：光源方向、时间（晨光/黄昏/夜景）、主色 + 辅色
5. **画面文字**：需要时用中文引号标注确切文案与位置
6. **画质**：清晰、细节完整、无水印、无多余文字

反例："一张非常好看的高清精美大气的图片" —— 全是空词，等于没描述。
正例："一只橘色短毛猫趴在木窗台上晒太阳，平视近景，右侧留白，暖晨光从左上方斜射，浅木色与奶油白主调，画面无文字"

### 固定收尾

每段提示词末尾统一追加一句，不要漏：

```
清晰，细节完整，无水印，无 logo，无边框，除指定文案外画面无其他文字
```

- 要出现文字时，只保留用户给的文案，逐字照抄，不加标点不加英文
- 画面里不该有的东西写进负面收尾，比正文里反复强调"不要 XX"更有效
- 负面词不要堆太长，5 项以内，只留这次真会翻车的那几项

## 一组图怎么出

用户要"一组""几张不同风格""系列延展"时：

1. 先固定主体、场景、配色、光线，**每张只变一个变量**（风格或构图），否则几张图对不上。
2. 张数默认 3 张，最多 6 张；超过 6 张先确认。
3. 全部同比例，命名统一。
4. 一次交付全部成品并按顺序排列，不要分批给。

## 文件命名

`主题-用途-比例-序号.ext`，例如 `橘猫-头像-1x1-01.png`。用中文、短、一眼能认出来；不要用时间戳或一串数字。

## 出图

按平台既定的图片生成流程与工具执行，本技能负责把需求收敛成提示词。改图类任务保持原图比例，主体与构图不动。

## 交付前自查

- 比例是否与用途匹配？文字是否逐字拼对，有没有乱码、多字或英文串？负面收尾是否加上了？
- 主体是否被裁掉或变形？改图任务中原图主体是否还在原位？
- 一组图之间主体、配色、光线是否一致？只有被要求的那一个变量不同？
- 只交付最终成品，不交付中间稿；文件名按规范重命名。
